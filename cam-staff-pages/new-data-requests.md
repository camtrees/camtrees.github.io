# {{ page.title }}

Use the pages in this section to request a new Cam Org, Hub, Parent Tree, Site, or
Volunteer to be added to the CAMTREES Database.

New data requests will be sent to the CAMTREES Database Administrator.
Submitting a request does not add information directly to the CAMTREES database.

{: .warning }
New Data Request pages are still under development. Please wait before using them.

### Available Requests

- **New Cam Org** – Request a new CAM Organization be added to CAMTREES.
- **New Hub** – Request a new Hub be added to CAMTREES.
- **New Parent Tree** – Request a new Parent Tree be added to CAMTREES.
- **New Site** – Request a new planting site be added to CAMTREES.
- **New Volunteeer** – Request a new Volunteeer be added to CAMTREES.
