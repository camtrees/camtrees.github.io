# {{ page.title }}

CAM Staff will use the <a href="https://five.epicollect.net/project/cam-new-data-request" target="_blank">CAM New Data Request</a> project to request new data to be added into the SQL System. 

### Available Requests

- **New Cam Org** – Request a new CAM Organization be added to CAMTREES.
- **New Hub** – Request a new Hub be added to CAMTREES.
- **New Parent Tree** – Request a new Parent Tree be added to CAMTREES.
- **New Site** – Request a new planting site be added to CAMTREES.
- **New Volunteer** – Request a new Volunteer be added to CAMTREES.

{: .warning }
Submitting a request does not add information directly into the CAMTREES database. Rather, that information is viewed and approved for addition by the database administrator.
